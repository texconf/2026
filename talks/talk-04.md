## 概要
数式を含むテキストを複数のメディアに展開することを考えます。
このとき各メディアの特性が制約となり、実現するためのフローが複雑になることがしばしばあります。

今回は、可搬性の高いテキストと Web とを対象としたとき、

* 数式・図式が綺麗に組まれること
* 和洋混植であること
* ワークフローが簡潔であること

という三つの要件を満たす仕組みを実現するための一つの試みをお話しします。

特に、TeX の組版の美しさを如何に Web メディアで活用するかという視点に立ち、
DVI を活用する方法を検討し、このアプローチの有用性と限界を見ます。
また、ワークフローを構築する上で実験的に制作した TeX 処理系（SabiTeX）について、
制作の経緯と得られた知見を簡単に紹介します。

## 前提知識

* LaTeX で文書を書いたことがあること。
* Web で数式を記述しようとしたことがあること。
* TeX 処理系が実際にテキストを処理する流れを簡単に把握していること。

TeX に関しては、第1部を聞いていただけると概ね知識の面では充分だと思います。
Web において数式を組む方法については、既存の方法との比較の中で講演中に説明しますが、経験があるとわかりやすいと思います。
